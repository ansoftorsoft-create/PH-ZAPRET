# 🚀 PH-ZAPRET (Android VPN)

Приложение для обхода блокировок и замедлений (YouTube, Discord и др.) на базе VpnService без необходимости Root-прав.

## 📥 Скачать приложение

Нажмите на кнопку ниже, чтобы скачать готовый `.apk` файл последней версии:

[![Download APK](https://img.shields.io/github/v/release/ansoftorsoft-create/PH-ZAPRET?label=Скачать%20APK&style=for-the-badge&color=green)](https://github.com/ansoftorsoft-create/PH-ZAPRET/releases/latest)

Или перейдите напрямую в раздел **[Releases](../../releases/latest)**.

## ✨ Особенности
* 🟢 **Без Root:** Использует встроенный Android `VpnService`.
* ⚡ **Запуск в один клик:** Быстрое включение и выключение туннеля.
* 🛠 **Оптимизация:** Перехват и модификация пакетов на локальном уровне.
